# Maintainers

This file exists because `.github/CODEOWNERS` assigns ownership of it, and because a
public repository has to answer "who decides?" without anyone having to ask.

`.github/CODEOWNERS` is the authoritative per-path list and it is what GitHub enforces
on a pull request. This table names the people; that file names the paths.

## What a maintainer does here

Reviews and merges pull requests, cuts releases (`RELEASES.md`), and decides the calls
that are not derivable from the code — the ones `GOVERNANCE.md` describes as requiring
a decision record rather than a commit message.

## Becoming a maintainer

There is no committee and no vote, because there is one maintainer. The honest
statement of the process today is: open pull requests, and if you end up reviewing
other people's as often as you open your own, ask.

This section will be replaced by something less personal the first time it needs to be.

## Contact

Security reports do **not** go through this file or the issue tracker — `SECURITY.md`
is the path, and it exists for the reason that a vulnerability disclosed in public is
a vulnerability disclosed to attackers first.

Everything else: open an issue.
