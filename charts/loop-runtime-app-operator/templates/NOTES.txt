LoopRuntime App Operator has been deployed.

1. Verify the deployment:
  kubectl get pods -l "app.kubernetes.io/name={{ include "loop-runtime-common.name" . }}" -n {{ .Release.Namespace }}

2. Check controller logs:
  kubectl logs -l "app.kubernetes.io/name={{ include "loop-runtime-common.name" . }}" -n {{ .Release.Namespace }} -f

3. Check leader election:
  kubectl get leases -n {{ .Release.Namespace }}

4. Run the Helm test:
  helm test {{ .Release.Name }} -n {{ .Release.Namespace }}
