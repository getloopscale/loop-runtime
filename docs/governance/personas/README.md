# Adversarial Personas — Independent Score Reviewers

**Purpose:** Recalibração de score de maturity usa **3 personas adversariais** rodando blind contra evidence + divergence data. Triangulação produz score com confidence 95-97% (não 99% — vide ADR D1 v1.2).

**Per ADR D4 do plano** `status-validation-and-doc-consolidation-plan.md`.

## The 3 Personas

| Persona | Bias Lens | File | Score Pressure |
|---------|-----------|------|----------------|
| **P1 — Vercel DD Engineer** | DX/CLI/onboarding | `vercel-dd-engineer.md` | Penaliza fricção em primeiro deploy |
| **P2 — Hostile VC Auditor** | Overclaim em pitch | `hostile-vc-auditor.md` | Penaliza aggregation + counting bias |
| **P3 — Paranoid SRE** | Production readiness | `paranoid-sre.md` | Penaliza chaos gaps + known-failing tests |

## Independence Requirement (T3.0 Hardening)

Para que matemática `~1 − (0.1)^3 ≈ 95-97%` seja válida, as 3 personas DEVEM rodar com **≥2 das 3 dimensões variadas**:

1. **Modelo:** atribuir 2+ modelos diferentes (opus/sonnet/haiku) OU usar `codex-rescue` skill para 1 das 3 (cross-vendor GPT)
2. **Temperature/seed:** P1 temp=0.7 seed=42 | P2 temp=0.3 seed=137 | P3 temp=0.5 seed=99
3. **System prompt:** os 3 persona files já são textualmente distintos (necessário, não suficiente)

Configuração concreta em `independence-config.yaml` (gerada por T3.0). Validador em `scripts/verify-independence.sh`.

## Invocation Pattern (T3.1)

```
Agent({
  subagent_type: "<per config>",
  description: "{persona} scoring",
  prompt: <load persona file> +
          "\n\nINPUT ARTIFACTS:\n" +
          "1. docs/governance/claim-catalog.yaml\n" +
          "2. docs/governance/evidence-gaps-report.md\n" +
          "3. docs/governance/divergence-report-2026-05-XX.md\n" +
          "4. docs/governance/code-audit-2026-05-XX.md\n" +
          "\nDo NOT read maturity-assessment.md or CLAUDE.md status text.\n" +
          "Score 7 dimensions 0-5 blind. Output: yaml per output schema."
})
```

**Blinding:** prompt explicitamente proíbe leitura das fontes de score atual.

## Convergence Rule (T3.2)

Para cada dimensão:
- Compute `median(p1, p2, p3)` + `std_dev(p1, p2, p3)`
- Se `std_dev > 0.3` → flag como HIGH-DELTA → meeting de reconciliação obrigatório (T3.3)
- Else: `final_score = median`

Math: cada persona errar +/-0.3 isoladamente é tolerável; 3 errarem na mesma direção é improvável (assumindo independência). Std-dev é proxy direto da confiança.

## Edge Cases

### Cross-Vendor Unavailable em CI
Fallback: 3 modelos Claude (opus/sonnet/haiku) + temperatures distintos (3 dimensão única variada). Log captura essa restrição em provenance file (`raw-runs.md`).

### Persona Output Malformed
Se 1 das 3 yaml não parsea → ERROR (não silently median-of-2). Plano define 3-source; 2-source viola contrato.

### All 3 Agree, Different Reasons
Convergência semântica ≠ convergência numérica. Manual review do `justification` bullets para detectar "all said 3.5 but for different reasons" (correlação spuriosa).

### Persona Refuses Adversarial Stance
Modelos com soft alignment podem suavizar críticas. Mitigação: prompt explicita stance ("Sua reputação depende de não deixar passar nada") + manual spot-check post-hoc.
