## Key Decisions

1. **Split:** TenantController → Gitea + AppProject + creates Environment CRs. EnvironmentController → namespace + RBAC + NetworkPolicy + Quota
2. **Migration:** Hybrid A+C — TenantController creates Environment CRs, EnvironmentController adopts existing namespaces by label
3. **Reconcile:** Always reconcile with CreateOrUpdate (no condition-gated skip)
4. **Deploy order:** EnvironmentController first (idle), then new TenantController
5. **Ownership:** `loopzero.io/managed-by: environment-controller` annotation on adopted resources
6. **Namespace explicit:** Environment spec.namespace.name is explicit, no magic naming

## Environment CRD Schema

- `spec.tenantRef.name`, `spec.environment`, `spec.namespace.name`, `spec.resourceQuota`, `spec.networkPolicy`
- `status.phase` (Pending|Active|Deleting|Failed), conditions (NamespaceReady, RBACReady, NetworkPolicyReady, QuotaReady)
- ownerReference to Tenant CR for cascade deletion

## Migration Safety

- EnvironmentController uses CreateOrUpdate (no delete+recreate)
- TenantController checks `managed-by` annotation before touching namespace resources
- Rollback: revert to old TenantController image — Environment CRs become orphaned but harmless
