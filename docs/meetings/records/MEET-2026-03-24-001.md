## Key Decisions

### 1. One CRD, one controller, phase-based dispatch
- `PlatformBootstrap` CRD with phases: Pending → ConfiguringGitea → ConfiguringArgoCD → WaitingForAPI → BootstrapComplete | Failed
- Each phase handler is a separate method (<40 lines)
- Conditions are observability signals, NOT control flow gates

### 2. DB seed via API internal endpoint (NOT in controller)
- Controller calls `POST /internal/bootstrap` on the API
- API owns all DB writes, validation, and migration awareness
- Controller just waits for API health then calls the endpoint

### 3. Token lifecycle: 90-day TTL
- No `expiresIn=0` (never-expiring tokens)
- Rotation deferred to future PlatformCredentialRotation controller
- `TokenRotationRequired` condition tracks expiry

### 4. No pods/exec — HTTP API only
- Controller uses Gitea HTTP admin API (Basic auth) for token creation
- No `kubectl exec` into pods

### 5. Convergence-based reconciliation
- Every phase: check-then-act-idempotently
- Gitea org exists? Skip. Token exists? Skip. Handle 422/409 as success.

## CRD Schema

```yaml
apiVersion: platform.loopzero.io/v1alpha1
kind: PlatformBootstrap
metadata:
  name: main
  namespace: loopzero-system
spec:
  gitea:
    adminSecretRef:
      name: gitea-admin-credentials
    organizations: [loopzero, loopzero-platform]
    tokenName: platform-bootstrap-token
    tokenScopes: [write:organization, write:repository]
  argocd:
    namespace: argocd
    adminSecretName: argocd-initial-admin-secret
    tokenTTLSeconds: 7776000
    repoCredentials:
      - name: gitea-repo-creds
        url: http://gitea-http.loopzero-system.svc:3000
  api:
    bootstrapEndpoint: http://loopzero-api.loopzero-system.svc:8080/internal/bootstrap
    healthEndpoint: http://loopzero-api.loopzero-system.svc:8080/api/v1/health
  timeouts:
    giteaReadySeconds: 120
    argocdReadySeconds: 120
    apiReadySeconds: 120
    totalBootstrapSeconds: 600
  maxRetries: 10
status:
  phase: ""
  message: ""
  retryCount: 0
  conditions: [GiteaReachable, GiteaConfigured, ArgoCDReachable, ArgoCDConfigured, APIHealthy, DatabaseSeeded, BootstrapComplete, TokenRotationRequired]
```

## Phase State Machine

```
Pending → ConfiguringGitea → ConfiguringArgoCD → WaitingForAPI → BootstrapComplete
   |            |                  |                  |
   +------------+------------------+------------------+→ Failed
```

Failed requires manual intervention (delete+reapply or force-retry annotation).
BootstrapComplete is terminal — no automatic re-bootstrap.

---

## Trade-offs Accepted

1. One controller (coupling) vs simpler operations
2. 90-day token TTL without rotation in v1
3. API dependency adds latency to bootstrap
4. No automatic drift correction in v1
5. pods/exec eliminated — HTTP API only
