## Committee
- state-guardian (cursor-state / period state machine / fencing / crash recovery)

## Decision
The `metering_cursor` construct (a high-water-mark cursor, correctly NOT one of the canonical 11 `Machine`s) is architecturally sound and ADR-9's period-split **atomicity** is provable and signed. But v1.5 re-introduces the round-1 "declared-test / missing-mechanism" failure class in TWO money-corrupting spots at the audited period boundary. Sign-off is WITHHELD until folded.

### Invariants checked
- cursor exactly-once advance ✅ (CAS `WHERE last_metered_at = $expected` + `$gen` fence; lost race = 0-row no-op = defer, never under-bill; double-advance impossible)
- **cursor monotonic advance ❌ (SC-1)** — ADR-4 CTE has no lower bound; backward NTP step → negative `elapsed` → counter DECREMENT + cursor rewind → double-bill next tick
- ADR-9 atomic split ✅ — one tx = all-or-nothing; crash between P1/P2 upserts rolls back both + the single cursor advance; "advanced with only one period written" unreachable. Closes round-1 INV-2/INV-3.
- **ADR-9 split DISPATCH ❌ (SC-2)** — same-period-vs-split chosen in Go (Go clock) while advance/delta use DB `now()`; at a period boundary the clocks straddle differently → misattribution or negative `head`. ADR-4's "same DB now()" property does not extend to the split decision.
- read-failure-holds-cursor ⚠️ (SC-3) — mechanism sound (LIST error → no write-tx → cursor untouched) but EC-1's "unconditional every tick" wording is one swallowed error from advancing over an unmeasured interval; HOLD invariant not stated; test asserts "no double" not "cursor UNCHANGED"
- crash recovery / idempotency ✅ — rollback leaves `$expected` intact → CAS retry idempotent; superseded leader fenced by gen
- period-independence lock ⚠️ (SC-4) — schema ✅ (PK `(tenant,metric,cell)`, no period col) but Row 13 verified only by a DDL test; behavioral half (post-split `last_metered_at == now()`, not `== B`) unproven
- terminal/timeout & panic ⚠️ (SC-5/SC-6) — cursor correctly outside `Machine`; `MeteringStalled` is the timeout-equivalent ✅; worker `recover()` honors leader binary discipline ✅. Gaps: cursor lifecycle across the Tenant machine undefined (orphan on delete; reused `tenant_id` → resurrection double-bill); fence subquery `$loop/$leaderCell` must single-source-bind to the lease providing `$gen` + exit on `ErrFenced`.

## Conditions (fold into plan v1.6 before /implement)

1. **(SC-1 — BLOCKER) Cursor monotonicity guard in the CTE.** Add `AND now() > metering_cursor.last_metered_at` to the WHERE of BOTH `MeterCompute` and `MeterComputeSplit` (backward clock → 0 rows → cursor HELD, no decrement/rewind). Defense-in-depth: `elapsed = GREATEST(LEAST(now()-$expected, $maxDelta), interval '0')`. **Spell out the guarded ADR-4 CTE AND the ADR-9 split CTE at matching SQL fidelity (prose is the round-1 gap).** Test: `TestMeterCompute_NegativeDeltaClockSkew_NoDecrement` must also assert `last_metered_at` UNCHANGED; add `TestMeterCompute_BackwardSkew_CursorNotRewound`.

2. **(SC-2 — BLOCKER) Split dispatch must be DB-clock-atomic.** Govern the same-period-vs-split decision by the DB `now()` that performs the advance, not a Go clock. Either (a) one unified writer that splits internally on `period_end($expected) < now()`, OR (b) two methods each with a period-agreement predicate in the WHERE (`MeterCompute: AND period_of(now()) = period_of($expected)`; split: `<>`) so a clock disagreement is a 0-row HOLD that self-corrects, never a misattribution/negative-head. Test: `TestMeterCompute_DispatchClockDisagreement_HoldsNotMisbills`.

3. **(SC-3) State the read-failure-holds invariant explicitly.** Task 3.1 `collect()` returns `(Σreq, error)`; non-nil error short-circuits BEFORE any `MeterCompute*` call (Rule 8 — no error-as-zero swallow); EC-1's "unconditional" scoped to a SUCCESSFUL empty list only. `TestMeteringLoop_PartialCellFailure_NoLostNoDouble` must assert the failed cell's `last_metered_at` UNCHANGED.

4. **(SC-4) Behavioral half of the period-independence lock.** `TestMeterComputeSplit_*` asserts post-split `last_metered_at == now()` (continuation), NOT `== B` — proving C9's "no reset at rollover".

5. **(SC-5) Cursor lifecycle at Tenant state boundaries.** `SeedMeteringCursor` seeds-if-absent to `now()` (EC-10) AND GC the cursor row on tenant DELETE (finalizer/reaper) so a reused `tenant_id` cannot bill a stale window; document/re-seed Suspend→Unsuspend resumption. Tests: `TestMeteringCursor_TenantDelete_GCsRow`, `TestMeteringCursor_ReprovisionedTenantId_SeedsFresh`. **NOTE: touches the Tenant reaper — confirm scope (may be a small new integration point, not just producer-internal).**

6. **(SC-6) Single-source the fence binding + honor exit-on-fence.** Bind the fence subquery's `$loop/$leaderCell` to the SAME lease whose `GenerationID` is `$gen`; `TestMeterCompute_FencedWriterRejected` uses a stale gen from the metering loop's OWN lease name; loop exits/stops writing on `ErrFenced` per `generation.go` contract pt 4.

## Residual risk accepted
- EC-6 fence-unresolved classification unspecified but conditioned + tested + SAFE direction (HOLD → under-bill, alarmed) — accept provided `TestMeterCompute_NoGenerationRow_IsLoudNotSilent` asserts a signal distinct from a normal lost-CAS.
- Risk-6 pin/evict stale cursor — per-cell keying freezes an orphan (safe); SC-5 GC covers the reuse case. LOW, accepted as documented.
- Cursor not in the canonical 11 — correct; no framework change needed.

## Guardian invariant status

## Anti-patterns flagged
- "Declared regression test with no design mechanism to satisfy it" (SC-1, SC-2) — the exact round-1 withhold class; the test passes on the happy path and the money-corruption only manifests at the period boundary the feature exists to protect.
- Two clocks governing one atomic decision (SC-2) — the DB-`now()` atomicity of ADR-4 silently not extended to the Go-side split dispatch.
