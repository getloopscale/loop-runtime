## Key Decisions

1. **Explicit `type=repository` Secrets** per tenant (not `repo-creds` templates)
2. **TenantController creates the GitRepositoryBinding CR** (ownerReference cascade)
3. **Credential hash annotation** on ArgoCD Secret for rotation detection
4. **Periodic reachability check** (5min RequeueAfter) via Gitea HTTP API
5. **v1 uses shared GITEA_TOKEN** with documented accepted risk; CRD supports per-tenant swap
6. **Finalizer cleans up ArgoCD Secret** by deterministic name, tolerates NotFound

## Security Accepted Risk (v1)

All tenants share one GITEA_TOKEN. Blast radius: compromised ArgoCD Secret exposes all repos.
Mitigation: CRD `credentialSecretRef` already supports per-tenant tokens — zero CRD changes needed.
Follow-up ticket required for per-tenant Gitea token scoping.

## CRD: GitRepositoryBinding

- ONE per (repo, consumer) pair
- Created by TenantController with ownerReference to Tenant
- Finalizer: `platform.loopzero.io/repo-binding-cleanup`
- Conditions: CredentialsResolved, RepositoryRegistered, RepositoryReachable, ConsumerHealthy
- `status.credentialHash` for rotation detection
