## Technical confrontation

- **Consensus challenged:** all 7 recommend APPROVE_WITH_CONDITIONS — but the agreement is grounded, not lazy. Four reviewers **independently** converged on step 7 (gate self-registration) being mis-classified as low-risk. That convergence is the meeting's strongest signal and drives MA-1/MA-3.
- **Live dissent amplified:** k8s-controller's "rename is cosmetic" is accepted as true — step 1 stays rename-only and MUST NOT be sold as de-smelling the god-package (MA-11). A real split-by-concern of `reconcilehelpers` is a separate future item.
- **Process divergence resolved:** principal + PDR both reject a single M9 mega-PR in favor of ≥8 atomic PRs. M9 stays one roadmap milestone delivered via 8 atomic `develop→main` PRs (MA-2). No T3 escalation — no contract changes.

## Decision

**APPROVED_WITH_CONDITIONS.** Proceed with M9's 8 steps under the mandatory actions below. Tier ratified as **T2**. Verification-architect's conditional veto is satisfied by MA-1/MA-3/MA-4. No blocker remains once the conditions are wired.

### Mandatory actions

- **MA-1 (PREREQUISITE, blocking):** Build `loopzero-ops quality --list` (emits the sorted registered gate set + a "wired-in-task-gates?" bit) and freeze `/tmp/m9-gateset.before` **before step 3**. This is the only detector for step-7 silent un-wire. Owner: Claude.
- **MA-2:** One atomic `develop→main` PR per step (8 PRs, not one M9 mega-PR). Each `behavior_change=none` → trivially revertible.
- **MA-3:** On steps 4 & 7, `loopzero-ops quality --list | sort` MUST equal the frozen baseline **byte-for-byte**; every registered gate resolves when invoked individually (no `unknown gate`). A dropped registration turns CI **red**.
- **MA-4:** Characterization test-function-name **set-diff (not count)** == ∅ for db(139)/services(502)/tenant(envtest specs)/pkg-quality/shared before their split steps. A silent test-drop is a BLOCKER, not a warning.
- **MA-5:** Name the `pkg/quality` relocation destination explicitly; prove via `go list` there is no new import edge into the future `loopzero-contracts` base (jwt/serviceauth/enforcement/plan). It imports enforcement/statemachine → must land DOWNSTREAM of contracts.
- **MA-6:** Step 5 builds on the existing `api/internal/db/generated/` (24 sqlc files) — no regen. `git diff --stat api/internal/db/generated/` empty; `sqlc-sync` + `sqlc-tx-prop` gates GREEN; no `sqlc generate` inside M9.
- **MA-7 (state INV-1, blocking):** The `store` layer stays the ONLY exported status/state-mutation path — `SafeTransition` + `UpdateReleaseStatus` in the same method + same transaction (`release_wrapper.go:283-326` pattern). Add a grep gate: any `api/internal/services/*` importing `db/generated` for a status UPDATE = FAIL.
- **MA-8 (state INV-4):** Keep `db/migrations/` + `schema.gen.sql` + `*_status_check` CHECK constraints in lockstep with `pkg/statemachine` states; do not orphan migrations in the split.
- **MA-9 (controller INV-5, blocking):** Step 2 ships ONE binary / ONE manager — both controllers register on the same `mgr` in `cmd/tenant-operator/main.go`; update all 5 registration call sites in one commit; move the full cohesive Environment file set + all 8 test files + a dedicated `suite_test.go` (no coverage drop); envtest proves both controllers registered AND a Tenant create still cascades an Environment reconcile; the orphan-ArgoCD-App fix stays tenant-side (no ArgoCD write from the `environment` package).
- **MA-10:** Capture a 4-layer steady-state baseline (`.claude/rules/steady-state-baseline.md`) before step 1 and after M9 completes (MANDATORY per the ≥5000-LOC merge trigger); cross-link from the M9 roadmap-run + closing commit. Per-step validation is hermetic (`go build && go test && task quality:gates && task lint` + envtest for steps 1/2) — NOT per-step Cleanroom/LIVE (null runtime delta; envtest IS the controller runtime proof).
- **MA-11:** Step 1 is rename-only. It MUST NOT be claimed to de-smell the god-package; a real split-by-concern of `reconcilehelpers` is a separate future item.
- **MA-12:** Sequence step 6 (services) LAST among the api splits; gate it on no open cross-repo decomposition branch touching `services/` (avoid M2–M5 merge churn).

### Alternatives rejected

- **Single M9 mega-PR** — rejected: un-reviewable, un-bisectable, buries a false behavior-preservation claim (principal C2, PDR C1).
- **Escalate to T3** — rejected: no CRD spec / `--json` / consumed-pkg-API / DB-schema / state-machine change; pure internal reorg (principal, all guardians).
- **Per-step Cleanroom+UP+LIVE** — rejected as validation theatre against a null runtime delta; hermetic + envtest is proportional (CVP tier argument). One baseline capture retained as the rollback anchor.
- **Drop step 1** — not taken: rename is cheap + real (generic god-folder), just not oversold (MA-11).
