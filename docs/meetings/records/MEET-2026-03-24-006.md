**Verdict:** APPROVED

## Key Decisions

1. **Each CRD owns its own cleanup** — TenantController stops doing child cleanup directly
2. **Cascade order:** Tenant waits for child CRs to disappear, then does own cleanup
3. **Environment finalizer:** force-delete pods, delete namespace, wait
4. **LoopZeroApplication finalizer:** delete owned ExposedRoute, wait
5. **ExposedRoute finalizer:** delete IngressRoute + Certificate CRs
6. **LoopZeroBuild/LoopZeroRelease:** no finalizers needed (TTL/state machine handles)
7. **Gitea token revocation** added to Tenant finalizer

## Finalizer Table

| CRD | Finalizer | Responsibility |
|-----|-----------|---------------|
| Tenant | loopzero.io/tenant-cleanup | Archive repo, revoke token, delete AppProject (after children gone) |
| Environment | loopzero.io/environment-cleanup | Delete namespace (force-delete pods first) |
| GitRepositoryBinding | loopzero.io/repo-binding-cleanup | Delete ArgoCD Secret |
| LoopZeroApplication | loopzero.io/app-cleanup | Delete owned ExposedRoute |
| ExposedRoute | loopzero.io/route-cleanup | Delete IngressRoute + Certificate |
