# LoopZero docs

Bundle OKF v0.2 único do repositório: 1199 concepts. Cada documento é um concept com
`type` no frontmatter; este índice é navegação, não um concept.

A árvore tem três origens, e a distinção importa para saber como ler cada documento:

| Onde | O que é | Ler como |
|---|---|---|
| as seções abaixo, fora de `wiki/` e `knowledge-base/` | referência viva de engenharia (arquitetura, operações, runbooks, ADRs) | verdade corrente; conserte quando divergir |
| [`wiki/`](wiki/index.md) | o wiki cumulativo do projeto — decisões, concepts, auditorias, planos, atas | conhecimento compilado e mantido |
| [`knowledge-base/`](knowledge-base/index.md) | artefatos de ciclo: auditorias, releases, roadmap-runs, grills | trilha de auditoria datada, história |

Termos e tecnologias que os documentos citam sem explicar têm casa própria em
[`glossary/`](glossary/index.md) e [`technologies/`](technologies/index.md).
