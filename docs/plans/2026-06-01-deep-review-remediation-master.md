## Sub-Plan B — Robustez Sistêmica (Interface Contracts)

> **Trigger:** `arch-016` SyncClient interface under-specification (root cause of L22) signals a CLASS of bugs. The 5-layer L22 fix (commit `098b6846`) closed one instance; this plan closes the systemic gap.
>
> **/to-plan slug:** `2026-06-01-p2-interface-contracts-robustness`

### Findings Pack (5)

| ID | Sev | Title | File:Line |
|----|-----|-------|-----------|
| `arch-016` | HIGH | `SyncClient` interface omits `ForceReconcile`, `GetSyncRevision`, `TerminateOperation`, `GetAppStatus` — wrappers silently swallow capabilities (L22 class) | `api/internal/services/build_orchestrator.go:154-159` (interface decl) |
| `code-001` | HIGH | Promotion orchestrator Lock1/Lock2 lacks re-verify pattern that Rollback correctly implements — concurrent promote can lost-update | `api/internal/services/promotion_orchestrator.go:214-236` vs `rollback_orchestrator.go:210-219` (reference) |
| `code-002` | MEDIUM | BuildKit Argo step has no `ActiveDeadlineSeconds`; reaper 30min times out before workflow 45min, orphan execution window | `api/internal/argo/buildkit.go` |
| `code-005` | MEDIUM | Env name hyphen ban documented at `sync_callback_activator.go:175` but regex em `routes/builds.go` not enforced — preview-env name collision still possible | `api/internal/routes/builds.go` |
| `code-006` | MEDIUM | `KubeMintingTokenProvider.Token()` returns "" before first mint; cascade 401 on startup triggers reactive refresh | `api/internal/argocd/kube_minting_token_provider.go` |

### Pattern Insight

All 5 findings share root: **dependency contracts (interfaces / regex / state machines) are looser than caller expectations**. Fix pattern is uniform:
1. Tighten interface to expose all required methods (arch-016, code-006)
2. Mirror correct re-verify pattern across siblings (code-001)
3. Make implicit contract explicit (code-002 deadline, code-005 regex)

### Scope (Governance Gate)

- `api/internal/services/build_orchestrator.go` (SyncClient interface widening)
- `api/internal/services/pg_circuit_breaker.go` (delegation methods — partly already done in 098b6846)
- `api/internal/services/promotion_orchestrator.go` (Lock2 re-verify)
- `api/internal/services/release_convergence_loop.go` (remove duck-typed assertions, use widened interface)
- `api/internal/argo/buildkit.go` + `workflow_builder.go` (ActiveDeadlineSeconds)
- `api/internal/routes/builds.go` (env name regex)
- `api/internal/argocd/kube_minting_token_provider.go` (block-on-first-mint pattern OR explicit boot delay)
- Tests for each
