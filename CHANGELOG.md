### Deprecated
- **Sprint C T6.1 — `X-Correlation-ID` request header deprecated; canonical form is `Correlation-ID` (RFC 6648)** per plan `2026-06-01-p3-infra-observability-test-debt` v1.1 ADR D5 (closes `val-002` MEDIUM). Routes `api/internal/routes/promote.go:130` and `rollback.go:121` previously read `X-Correlation-ID` directly while `builds.go` + `projects.go` + `secrets.go` already used the canonical `Correlation-ID` — distributed tracing broke silently for promote + rollback because the middleware-injected canonical header never reached those handlers. Both forms are now accepted via the new `api/internal/correlation.Read(r)` helper for one release cycle; legacy `X-Correlation-ID` hits emit a `slog.Warn` naming the caller's `User-Agent` so operators can identify lagging CLI clients. After one release cycle the fallback drops in a future major; callers MUST migrate to `Correlation-ID`. Migration steps for SDK consumers: change any `request.headers["X-Correlation-ID"] = id` to `request.headers["Correlation-ID"] = id`.
