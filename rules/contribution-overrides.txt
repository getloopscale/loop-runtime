# THIS PROJECT's contribution conventions, overriding the kit's defaults.
#
# `rules/contribution-conventions.md` is the kit's contract and a reinstall overwrites
# it. This file is yours: it ships empty, a reinstall preserves it, and
# `check_contribution_conventions.py` reads it before applying any default.
#
# Format:  key = value        (one per line; `#` comments; unknown keys are refused)
#
# Keys:
#   commit_types    = comma-separated. REPLACES the kit's set
#   commit_scopes   = comma-separated. When set, a scope outside it is refused
#   subject_max     = integer. Default 72
#   body_required   = comma-separated types. Default: feat,fix
#   branch_trunk    = the trunk's name, when it is not detected from origin/HEAD
#
# TWO THINGS CANNOT BE OVERRIDDEN and an attempt is refused rather than ignored:
#
#   the co-authorship refusal — the author of a commit is one person, and a trailer
#   crediting a tool misattributes the accountability authorship carries
#
#   the secrets rule for issues — no token, cookie, password or customer data in an
#   issue body, ever
#
# Example:
#   commit_types = fix,feat,docs,test,chore,perf,build,ci,revert,refactor,deps
#   subject_max  = 80

# ---------------------------------------------------------------------------
# `merge` is a type of THIS repository, and not a concession.
#
# The `workspace -> develop -> main` flow (rules/git-safety.md) produces merges by
# design: 24 of the commits that exist only on `main` are release PR merges, none of
# them carrying content of their own. A merge commit named `merge(B-069):` says what
# it is and which item it belongs to; forcing it into `chore(merge):` would say less.
#
# `subject_max` at 85 is the p90 measured over 300 subjects of this repository, not the
# 50 or 72 every guide repeats — a limit that fails 44% of what the repository has
# always done teaches people to ignore the checker.
commit_types = fix,feat,test,docs,refactor,chore,perf,build,ci,revert,merge
subject_max  = 85

# AND A LESSON THAT COST A COMMIT: the scope is the AREA, not the item.
#
# `merge(B-069):` was refused by `header_shape`, and the reason is not the type — it is
# that `B-069` is uppercase and the scope requires lowercase kebab-case. `merge(api):`
# matches. §5.1 of `~/.claude/CLAUDE.md` already said where the number goes: in the
# commit MESSAGE, in the PR body, in the CHANGELOG. The scope slot is none of those.

# 99-character subject against the 85 declared above. It is recorded rather than fixed,

# behind HEAD, and rewriting four commits over fourteen characters costs more than the

# it on its own.
#
# What is NOT done is moving the limit to 99 so the gate goes green. 85 is the p90
