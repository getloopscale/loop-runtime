# Host port registry — read by `loop-runtime-ops leak ports`.
#
# POLARITY: CLOSED BY DEFAULT. A port listening on 0.0.0.0 that does not appear
# here is a FAILURE, not a silence. The firewall that existed before did the
# opposite — open by default, closed by list — and the result was measured on
# 2026-08-10: 39 ports listening, 20 on the block list, and 17 reachable from the
# internet without being on any list. Among them ArgoCD, the secrets cluster and
# identity without TLS.
#
# The cause was not carelessness: the block list was written when the clusters had
# other names, and everything that came up afterwards was born outside it. A DENY
# list ages towards the unsafe side — an ALLOW list ages towards the safe side,
# the only acceptable direction for a security rule.
#
# FORMAT
#   <port> | <class> | <who consumes it, and how that was measured>
#
# CLASSES
#   edge      — the edge (Caddy) publishes it over HTTPS; the raw port must NOT be reachable
#   external  — legitimate consumer OUTSIDE the host, named and measured. Requires evidence.
#   host      — consumed by the host itself (Caddy, scripts); never from the internet
#   admin     — infrastructure panel or API; never from the internet
#   pending   — declared, consumer not yet measured; neither closed nor accepted
#
# Only the `external` class stays reachable from the internet. Every other class is
# closed. Adding an `external` row without naming the consumer and saying how it was
# measured is the same as switching the control off.
