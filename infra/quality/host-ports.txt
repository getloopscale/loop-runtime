# Registro de portas do host — lido por `loopzero-ops leak ports`.
#
# POLARIDADE: FECHADO POR PADRÃO. Uma porta que escuta em 0.0.0.0 e não aparece aqui é
# uma REPROVAÇÃO, não um silêncio. O firewall que existia antes fazia o inverso — abria
# por padrão e fechava por lista —, e o resultado foi medido em 2026-08-10: 39 portas
# escutando, 20 na lista de bloqueio, e 17 alcançáveis da internet sem estar em lista
# nenhuma. Entre elas o ArgoCD, o cluster de segredos e a identidade sem TLS.
#
# A causa não foi descuido: a lista de bloqueio foi escrita quando os clusters se
# chamavam mgmt/workload/runtime-2/vault, e tudo que subiu depois nasceu fora dela. Uma
# lista de NEGAÇÃO envelhece para o lado inseguro — a de PERMISSÃO envelhece para o lado
# seguro, que é a única direção aceitável numa regra de segurança.
#
# FORMATO
#   <porta> | <classe> | <quem consome, e como isso foi medido>
#
# CLASSES
#   edge      — a borda (Caddy) publica em HTTPS; a porta crua NÃO deve ser alcançável
#   external  — consumidor legítimo FORA do host, nomeado e medido. Exige evidência.
#   host      — consumido pelo próprio host (Caddy, scripts); nunca da internet
#   admin     — painel ou API de infraestrutura; nunca da internet
#
# Só a classe `external` permanece alcançável da internet. Todas as outras são fechadas.
# Adicionar uma linha `external` sem nomear o consumidor e sem dizer como foi medido é o
# mesmo que desligar o controle.
