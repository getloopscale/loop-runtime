# test-skip-absent-path — declared path-guarded skips (B-180)
#
# A test under one of the scanned trees (infra/tests/ and api/, per
# DefaultScanDirs) that probes a path and skips when it is missing is
# conditional in FORM and unconditional in FACT once that path leaves the tree:
# the skip branch becomes the only branch, the package still prints `ok`, and
# every assertion below the guard is dead. B-169 removed one such test; B-180
# removed four more and added this gate so the class cannot return silently.
#
# Every line here is an absence this repository has looked at and decided to
# carry for now. The gate prints them on EVERY run, pass or fail — a tracked
# absence must never be quieter than a fresh one — and it FAILS when:
#   - a path-guarded skip is absent and NOT listed here;
#   - a listed path comes BACK (the guard is conditional again, the line is
#     stale prose);
#   - a listed skip is not re-found by the scan (the skip went away, or the
#     gate's detector stopped detecting — either way somebody must look).
#
# Format: four TAB-separated fields.
#   <test file, repo-relative>  <enclosing func>  <guarded path, repo-relative>  <why, naming what covers this instead>
#
# The probe may be written inline or one level down inside a same-package
# predicate the guard calls (`if !cliSrcPresent() { t.Skip() }`) — B-183 taught
# the gate to read the second form, after an audit walked the class back in with
# a one-line refactor.
#
# The right way to leave this file is to delete the line, not to add one.
#
