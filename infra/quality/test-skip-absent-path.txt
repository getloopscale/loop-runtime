# test-skip-absent-path — declared path-guarded skips (B-180)
#
# A test under infra/tests/ that stats a path and skips when it is missing is
# conditional in FORM and unconditional in FACT once that path leaves the tree:
# the skip branch becomes the only branch, the package still prints `ok`, and
# every assertion below the guard is dead. B-169 removed one such test; B-180
# removed four more and added this gate so the class cannot return silently.
#
# Every line here is an absence this repository has looked at and decided to
# carry for now. The gate prints them on EVERY run, pass or fail — a tracked
# absence must never be quieter than a fresh one — and it FAILS when:
#   - a path-guarded skip is absent and NOT listed here;
#   - a listed path comes BACK (the guard is conditional again, the line is
#     stale prose);
#   - a listed skip is not re-found by the scan (the skip went away, or the
#     gate's detector stopped detecting — either way somebody must look).
#
# Format: four TAB-separated fields.
#   <test file, repo-relative>  <enclosing func>  <guarded path, repo-relative>  <why, naming what covers this instead>
#
# The right way to leave this file is to delete the line, not to add one.
#
infra/tests/unit/build_images_split_operators_test.go	readBuildImagesYaml	.github/workflows/build-images.yml	Deleted in 5b32b76f0 (2026-05-23, "remove GitHub Actions CI/CD — not used"), so this guard has fired on every run since. Measured 2026-09-05, and the skip's own message is stale in its premise: GitHub Actions came BACK in 32bb066b3 (the AM6 supply-chain pipeline), and .github/workflows/ today holds build-publish.yml, ci.yml, release-artifacts.yml and workflow-hygiene.yml — none of which carries the four split-operator jobs this test indexes. The four Dockerfiles themselves are real (operators/Dockerfile.{tenant,app,preview,platform}-operator) and are built by the Tiltfile and taskfiles/dev.yml, and the image half is re-asserted by the base-image-digest and prod-image-digests gates. What nothing re-asserts is the four-JOB wiring, because the file that held it is gone. Settling that — restore the jobs in the live workflow, or delete the three tests that read it — is B-182.
