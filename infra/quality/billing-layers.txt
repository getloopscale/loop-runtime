# Registry of the billing layers — read by `loopzero-ops quality billing-layers`.
#
# POLARITY: CLOSED BY DEFAULT. A file that references a billing input and does not
# appear here is a FAILURE, not a silence.
#
# WHY IT EXISTS
#   On 2026-08-11, FIVE independent layers were measured in which missing billing
#   configuration was tolerated, all failing towards the SAME side — do not charge,
#   do not block, do not verify — and none of them saying so. The dashboard served for
#   20h with plan and price on screen while the secret that verifies payments did not
#   exist in the cluster.
#   Each choice is defensible in isolation. The direction of the error is the finding: a
#   billing system that always errs to the same side is not tolerant, it is biased. (B-038)
#
# FORMAT
#   The section names below are format keys matched literally by the parser, which
#   refuses an unknown one by name.
#   [anchor]      one input per line — the reference that marks a file as a candidate
#   [floor]       the minimum number of layers; fewer than that FAILS
#   [layers]      <id> | <repo> | <files,comma-separated> | <guard> | <how it degrades>
#   [references]  <file> | <why it is NOT a layer>
#
# GUARDS
#   gate:<name>   a loopzero-ops gate covers it — resolves only if the gate is RUN in quality.yml
#   test:<path>   a test asserts the invariant (checked by EXISTENCE, not content)
#   open:B-NNN    declared debt with an owner — resolves ONLY while the [debts] section
#                 below records the item as open (raw, triaged, approved or planned);
#                 shipped and killed FAIL
#
# [debts]         <B-NNN> | <status> | <what closing it puts in place>
#   The debt ledger lives HERE, versioned, and not in BACKLOG.md: BACKLOG.md is
#   gitignored, so a gate reading it failed on every clone and passed only on the
#   one machine that had it. Closing a debt means editing its status in this file,
#   in the same diff that swaps the layer's guard for `gate:` or `test:`.
#
# THE RATCHET: closing an `open:` item without swapping the guard FAILS. That is what
# stops the debt from becoming a rug to sweep things under — without it, marking B-033 as
# delivered would be enough to leave the layer uncovered and silent while this file still
# claimed somebody takes care of it.
