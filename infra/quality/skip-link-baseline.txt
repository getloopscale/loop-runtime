# Skip-link baseline (Quality Gates plan T6.5).
#
# Format: one `relative/path/to/file.ext<TAB>normalized skip line` per non-comment
# line. Lines starting with `#` and blank lines are ignored.
#
# The key is FILE + the text of the skip itself, NOT file:LINE. The positional
# form made the baseline decay: any edit above a grandfathered skip re-reported
# it as new, so on 2026-08-06 a 145-entry baseline was matching almost nothing
# and the gate reported 189 "NEW" skips it had already accepted. A gate whose
# output is mostly noise stops being read.
#
# Regenerate deliberately, never as a way to silence a finding:
#   /tmp/loopzero-ops quality skip-link --emit-baseline > infra/quality/skip-link-baseline.txt
# then restore this header. Adding an entry by hand is how a real new skip gets
# grandfathered without anyone deciding to.
#
# Frozen 2026-08-06. Most entries are CONDITIONAL environment skips (no cluster,
# no credential, -short mode), which are the correct pattern for an optional
# integration test rather than debt. The gate's job is to catch a NEW skip added
# without an issue link; it does not attempt to tell the two apart.
