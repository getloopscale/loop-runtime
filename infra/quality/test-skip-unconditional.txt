# test-skip-unconditional — declared bare skips with code underneath (B-184)
#
# A test that opens with a BARE t.Skip — no guard, no condition — and carries
# statements underneath it is a test that has not run since the line was added,
# while the package goes on printing `ok`. A skip is not a branch: it aborts the
# function, so everything below it is unreachable and reads like a live
# assertion anyway. B-169 and B-180 removed this damage in the path-guarded
# spelling; B-184 removed eight sites of it in the unguarded one and added this
# gate so the class cannot return silently.
#
# Every line here is a site this repository has looked at and decided to carry.
# The gate prints them on EVERY run, pass or fail — a declared site must never
# be quieter than a fresh one — and it FAILS when:
#   - an unconditional skip has statements after it and is NOT listed here;
#   - a listed site is not re-found by the scan. That is the floor a
#     skip-counting check cannot reach: the anchor is the whole shape (file,
#     function, AND statements following the skip), so if the trailing-statement
#     test ever stops working, this line goes unmatched and the gate goes red.
#     Either the site was fixed and this line is stale prose, or the detector
#     stopped detecting. Both need a human; neither is a pass.
#
# Format: three TAB-separated fields.
#   <test file, repo-relative>  <enclosing func>  <why the code below still stands>
#
# One function may hold at most one declared site: the gate refuses to run
# rather than let a single line answer for two.
#
# The right way to leave this file is to delete the line, not to add one.
#
api/tests/integration/owner_maintenance_absent_test.go	openAnyRole	Not a dead assertion: openAnyRole is a HELPER, not a test, and the only statement under its t.Skip is `return nil, nil` — the tail Go requires of a function with results, reachable by nothing and asserting nothing. It is declared rather than forgiven by a rule because an automatic "trailing returns are fine" exemption would leave this pin EMPTY, and an empty pin re-find floor protects nothing; this one line is what anchors the gate's trailing-statement detector to a live site. The skip itself is the deliberate shape, not an accident: the function fails hard via t.Fatal when LOOPRUNTIME_RLS_AUDIT_REQUIRE=1 (which CI sets) and only skips on a developer machine with no reachable database, so the isolation control it feeds is exercised where it matters. That tension is tracked upstream at https://github.com/getloopscale/loop-runtime/issues/289.
