# Edge exposure registry — read by `loopzero-ops quality proxy-exposure`.
#
# Every `reverse_proxy` in infra/local/Caddyfile must have a row here. A proxy
# inherits its response contract from whatever sits behind it, so what reaches
# the browser is invisible in this repository unless somebody writes it down.
#
# Format: <site> <path> | <class> | <rationale>
#   <path> is `-` for a site-level proxy with no enclosing handle.
#
# Classes:
#   filtered — the edge restricts what reaches the client (field allowlist,
#              narrowed sub-path, rewritten body).
#   internal — the upstream returns no user data at all (static assets,
#              websockets, inbound webhooks whose response never reaches a
#              browser). Nothing to leak.
#   reviewed — full passthrough, looked at, accepted. The rationale is what
#              separates this from an oversight.
#
# `reviewed` is NOT a rubber stamp: it means someone read the upstream's
# response and decided the client needs it. When that is not true, the row
# should be `filtered` and the edge should actually filter.
#
# Frozen 2026-08-06 against the 26 proxies then present.
