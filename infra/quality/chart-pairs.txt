# Charts that exist in BOTH trees and must be kept in parity — read by
# `loopzero-ops quality chart-pairs`, `helm-drift` and `helm-overlap-parity`.
# This file is the single source of truth for which charts form a pair.
#
# `infra/helm/` and `charts/` coexist by design (ADR D1): the first is bootstrap,
# installed by Helmfile L2; the second is the published OCI chart consumed by ArgoCD
# L3. When a chart exists in both, CLAUDE.md requires parity — "when patching one,
# apply the same fix to the other" — and the only way to say which one is meant is
# the path.
#
# The registry exists because the prose drifted once: CLAUDE.md claimed THREE pairs,
# including `loopzero-admission-policies`, and `infra/helm/loopzero-admission-policies` never
# existed. The chart-pairs gate compares this list with disk: a same-name pair on
# disk that is not declared fails, and a declaration whose chart is gone fails too.
#
# A pair whose two charts carry DIFFERENT names (a conceptual pair) cannot be found
# by name on disk, so it exists only because it is declared here.
#
# Refer to each side by its path, never by the bare name:
#   "infra/helm/loopzero-api" = the bootstrap one, installed by Helmfile
#   "charts/loopzero-api"     = the published OCI one, consumed by ArgoCD
#
# Format: <infra/helm dir> | <charts dir> | <what each side is>

loopzero-api | loopzero-api | infra/helm bootstraps the engine on the core cluster; charts/ is the OCI chart ArgoCD consumes
